# 10_PERSONAS — 사용자 페르소나

본인 1인 사용이지만, 객관화를 위해 페르소나로 기술.

## P1: "바이브 코더 본인" (유일 사용자)

### 역할
- 솔로 풀스택 개발자 + 디자인+기획 겸업
- 여러 프로젝트(`nunchi`, `moodbit`, `emotion-lab`, 디자인 시스템 등) 동시 운영
- AI 페어 프로그래밍에 깊이 의존, Claude Code 일상 사용

### 환경
- **장비**: MacBook (Apple Silicon, macOS 26 Tahoe)
- **에디터**: 별도 IDE 사용 (Cursor / VS Code / Xcode 혼용)
- **노트**: Obsidian Vault — 모든 기획/회고/메모가 여기 모임
- **소통**: Telegram을 봇 활용 인터페이스로 적극 사용 (모바일 ↔ 책상)
- **이미 사용 중**: claude-forge 하네스, oh-my-claudecode, Plankton 등 도구 다수

### 페인포인트 (Yuminai가 풀어야 함)
1. **컨텍스트 복붙 지옥**: Obsidian 노트를 매번 복사 → 터미널의 `claude` 입력창에 붙여넣기. 코드 결과는 다시 노트로 옮겨 정리
2. **세션 휘발**: `claude` 종료하면 대화 사라짐. 다시 시작할 때 컨텍스트 복원이 수동
3. **자리 이탈 시 단절**: Claude가 작업 중일 때 자리 뜨면 진행 상황 모름. 모바일에서 다시 트리거 못 함
4. **멀티 워크스페이스 병렬 어려움**: tmux/iterm 탭으로 분리하지만 컨텍스트가 섞임
5. **하네스 적용 마찰**: claude-forge의 rules/agents가 프로젝트별로 다른데 매번 수동 셋업
6. **요약 노동**: 작업 끝나면 Obsidian Daily Note에 수동으로 무엇을 했는지 기록 (자동화 가능한데 안 함)

### 사용 시나리오 (3개)

#### S1. 아침 루틴 (10분)
1. Yuminai 실행 → "오늘의 워크스페이스" 추천 (어제 진행 + 캘린더)
2. 워크스페이스 열기 → 어제 마지막 세션 + Obsidian Daily Note 자동 컨텍스트
3. 채팅창에 "오늘 할 것 목록 만들어줘" → Claude가 Daily Note + 진행 중 PR 분석해서 답변

#### S2. 깊은 작업 (1시간 자리 이탈)
1. 큰 리팩토링 명령을 채팅에 입력 → Claude가 Plan → 사용자 승인 → 실행 시작
2. 사용자: 점심 먹으러 외출 (laptop 닫음, but 백그라운드 실행은 별도 — 우선 sleep 시 일시정지)
3. 돌아옴 → Yuminai 깨움 → "어디까지 했어?" → 진행 상황 요약 + 남은 step 표시
4. 완료 시 Telegram에 알림 + Obsidian Daily Note에 작업 로그 자동 append

#### S3. 모바일 ↔ 데스크탑 (리모트 트리거)
1. 외출 중, Telegram 봇에 "moodbit PR #42 머지하고 staging 배포 확인" 메시지
2. 데스크탑 Yuminai가 알림 수신 → 워크스페이스 `moodbit` 활성화 → Claude에게 명령 전달
3. 진행 상황 Telegram으로 1분마다 업데이트
4. 완료 시 결과 요약 + 만약 실패 시 사용자 의사결정 요청 (Telegram inline keyboard)

### 사용하지 않을 시나리오
- 실시간 화상 회의 (Yuminai는 동기 도구 아님)
- 코드 직접 편집 (별도 에디터 담당)
- 디자인 작업 (Figma/Pencil 별도)

## P2: "공유받은 사람" (출시 후 가능성, 현재 비범위)

장기적으로 본 도구가 안정되면 친한 개발자 1~2명에게 공유 가능. 단, MVP 단계에선 *전혀 고려하지 않음*. 멀티유저/협업 기능 추가 없음.

## 안티 페르소나 (이 사람은 사용자가 아님)

- **AI 코딩 신규 입문자**: Yuminai는 Claude Code 셋업/기본 개념을 가르치지 않음
- **팀 리드**: 협업 기능 없음
- **비개발자**: 기획자/디자이너 위주 사용 시 불필요한 복잡성
