설치 방법 (택 1)

【 1. 자동 설치 (권장) 】

  install.command 를 더블 클릭하세요.
  - Applications 폴더 자동 복사
  - Gatekeeper 차단 자동 해제
  - 설치 후 자동 실행

  처음 더블클릭 시 macOS가
  "확인되지 않은 개발자" 경고를 띄울 수 있습니다.
  → install.command 를 우클릭 → 열기 → 그래도 열기

【 2. 수동 설치 】

  ① Yuminai.app 을 Applications 폴더로 드래그
  ② Applications 폴더에서 Yuminai.app 우클릭 → 열기
  ③ "확인되지 않은 개발자" 경고 → 그래도 열기

  안 열리면:
    시스템 설정 → 개인정보 보호 및 보안
    → 하단의 "Yuminai이(가) 차단됨..." → 그래도 열기
